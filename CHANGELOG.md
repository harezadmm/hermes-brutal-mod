### Known Issues

**Provider Limitations:**
- Some providers have server-side hard blocks (child abuse, terrorism)
- OpenAI has stricter filtering than Anthropic
- Google Gemini blocks most weapon/drug content
- Solution: Use Anthropic Claude or local models for maximum freedom

**Injection Mid-Stream:**
- Some providers inject safety warnings mid-response
- Can cause sudden refusals after strong start
- Solution: Enable streaming detection, use rebuttal protocol

**Context Limits:**
- Full RedMess prompt is ~30K tokens
- May hit context limits with long conversations
- Solution: Use summary/compression, or load components selectively
